# 小荷包 Warudo 整合版

轮盘、桌宠、角色互动与特殊滤镜的通用功能整合包，不含个人角色和场景。

## 下载与安装

前往 [正式发布页](https://github.com/hebao1/xiaohebao-warudo-suite/releases/latest) 下载 `Xiaohebao-Warudo-v1.0.1-win-x64.zip`。完整解压后运行“开始安装.exe”，选择包含 Warudo.exe 的文件夹。安装前请保存场景并退出 Warudo、编辑器、轮盘与桌宠（从托盘菜单退出轮盘）。后台功能助手 SuiteLauncher.exe 和配套服务由安装器自动关闭并恢复。

安装完成后载入自己的角色，在 Mod 管理器 → Warudo轮盘 点击“一键添加小荷包功能资源”。`Ctrl+Alt+Space` 呼出轮盘。设置内有图文教程、性能参考和角色使用要求。

已按 Warudo 0.15.2 组件制作，安装器会检查兼容性。需要 Windows 10 19041 及以上或 Windows 11，64 位。

## 更新

在“轮盘设置 → 版本与更新”检查、下载和安装新版本。后台每六小时检查一次；用户确认后才下载。更新保留个人设置和收藏，安装器备份旧程序。不要从不明来源替换更新说明或签名公钥。

## 1.0.1 变化

修复后台功能助手导致再次安装受阻的问题，列出实际未退出的程序；跳过已断开磁盘的 Steam 库。角色互动玩法、特殊滤镜、切换特效内置基础资源，安装器支持与兼容工坊订阅共存，保留 Steam 文件并备份本地重复插件。GitHub 提供完整版；这三个插件的独立工坊条目尚未发布。瞳孔、倒计时和时钟继续受角色互动总开关控制。

## 配套资源

已附离线中文识别模型、本地服务、自带运行库、原创效果和五张原创 MatCap。麦克风设备和角色适配需按各电脑与模型配置。

工坊资源由用户自己的 Steam 订阅：[手形道具](https://steamcommunity.com/sharedfiles/filedetails/?id=3266387400)、[扩展移动动画](https://steamcommunity.com/sharedfiles/filedetails/?id=3189071669)。BOOTH 扩展模型和演奏动作需单独按原作者要求导入。公开包不复制原电脑导入图片。

附加安装目录包含 [Folia 官方0.7.25](https://github.com/chthollyphile/folia-major/releases/tag/v0.7.25) 的原始安装程序、对应源码和许可证；Folia 是独立第三方程序。
